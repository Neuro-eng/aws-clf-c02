Domain 1: Cloud Concepts · 24%
  • 6 advantages of cloud: trade fixed expense for variable expense; massive economies of scale; stop guessing capacity; increase speed and agility; stop spending on running data centers; go global in minutes.
  • Service models: IaaS (EC2, you manage OS and up), PaaS (Elastic Beanstalk, you manage the app), SaaS (finished software). Deployment: cloud, hybrid, on-premises.
  • Global infrastructure: Region (geographic area) contains multiple Availability Zones (isolated data centers). Edge locations serve CloudFront and Route 53 content close to users. Multi-AZ gives high availability. Multi-Region gives disaster recovery and lower latency.
  • Terms: scalability handles growth; elasticity scales out and in automatically; high availability keeps running through failures; fault tolerance keeps running with no interruption.
  • Well-Architected pillars (6): Operational Excellence, Security, Reliability, Performance Efficiency, Cost Optimization, Sustainability.
  • CAF perspectives (6): Business, People, Governance, Platform, Security, Operations.
  • Migration 7 Rs: Retire, Retain, Rehost (lift and shift), Relocate, Repurchase, Replatform, Refactor.
Domain 2: Security and Compliance · 30%
  • Shared responsibility: AWS secures the cloud (hardware, facilities, network, hypervisor, managed-service infrastructure). You secure what is in the cloud (data, IAM, guest OS patching on EC2, security groups, encryption choices). The more managed the service (S3, DynamoDB), the more AWS handles.
  • IAM: global and free. Users, groups, roles (temporary credentials), policies (JSON permissions). Least privilege, MFA, no daily root use, no access keys in code. Root user is only for a few account-level tasks.
  • Security groups are stateful, work at instance level, allow rules only. NACLs are stateless, work at subnet level, allow and deny.
  • Threat and data protection: GuardDuty (threat detection from logs), Inspector (vulnerability scans), Macie (PII in S3), Shield (DDoS), WAF (web exploits), Detective (investigate), Security Hub (central findings).
  • Encryption and secrets: KMS (keys), CloudHSM (dedicated hardware), Secrets Manager (store and rotate secrets), ACM (TLS certificates). Encrypt at rest and in transit.
  • Governance and audit: CloudTrail (API calls), CloudWatch (metrics, logs, alarms), Config (resource configuration and compliance), Artifact (compliance reports), Organizations with service control policies, Trusted Advisor (best-practice checks).
  • Identity for people: Cognito (app customers), IAM Identity Center (employee SSO across accounts).
Domain 3: Cloud Technology and Services · 34%
  • Compute: EC2 (virtual servers), Auto Scaling, Elastic Load Balancing, Lambda (serverless, event-driven, up to 15 minutes), ECS and EKS (containers; EKS is Kubernetes), Fargate (serverless containers), Elastic Beanstalk (deploy apps, PaaS), Lightsail (simple virtual servers), Outposts (AWS on premises), Batch.
  • Storage: S3 (object, 11 nines durability), EBS (block, one AZ, attaches to EC2), EFS (shared Linux file system), FSx (Windows file server and others), Storage Gateway (hybrid), AWS Backup.
  • S3 classes: Standard, Intelligent-Tiering (unknown access patterns), Standard-IA, One Zone-IA (single AZ), Glacier Instant Retrieval, Glacier Flexible Retrieval, Glacier Deep Archive (cheapest, slowest).
  • Databases: RDS (managed relational), Aurora (high-performance MySQL/PostgreSQL compatible), DynamoDB (NoSQL key-value), ElastiCache (in-memory cache), Redshift (data warehouse), DocumentDB (MongoDB compatible), Neptune (graph), DMS (migrate databases).
  • Networking: VPC (isolated network, public and private subnets, internet gateway, NAT gateway), Route 53 (DNS), CloudFront (CDN), Direct Connect (private line), Site-to-Site VPN (encrypted over internet), Global Accelerator, API Gateway.
  • Management and deployment: CloudFormation (infrastructure as code), Systems Manager, CloudWatch, CodeBuild, CodeDeploy, CodePipeline, X-Ray (tracing).
  • Analytics and integration: Athena (SQL on S3), Glue (ETL), EMR (big data), Kinesis (streaming), QuickSight (dashboards), OpenSearch; SQS (queue), SNS (notifications), EventBridge (events), Step Functions (workflows).
  • AI/ML: SageMaker (build, train, deploy), Rekognition (images), Comprehend (text), Lex (chatbots), Polly (text to speech), Transcribe (speech to text), Translate, Textract (documents), Bedrock (foundation models for generative AI), Amazon Q (assistant).
Domain 4: Billing, Pricing and Support · 12%
  • EC2 pricing: On-Demand (no commitment), Savings Plans and Reserved Instances (1 or 3 years, up to roughly 72% off), Spot (up to 90% off, can be interrupted), Dedicated Hosts (licensing and compliance), Capacity Reservations.
  • You pay for compute, storage and outbound data transfer. Inbound data transfer is free. Free Tier terms change, so check the current rules on AWS.
  • Cost tools: Pricing Calculator (estimate future), Cost Explorer (analyze past), Budgets (alerts), Cost and Usage Report (detailed data), cost allocation tags, Compute Optimizer (right-sizing), Organizations (consolidated billing and shared discounts).
  • Support: every plan includes account and billing support and access to documentation and AWS re:Post. Higher tiers add faster technical support, and the top tier adds a Technical Account Manager. AWS has changed plan names recently, so confirm the current list on the AWS Support page.
  • Other help: Trusted Advisor, Health Dashboard, AWS Marketplace, Partner Network, Professional Services, Skill Builder training.

Exam-week and exam-day tips

  • Aim for 80%+ on at least three different question sets before booking.
  • Read the last line of the question first, then look for keywords: cost-effective, least operational overhead, highly available, managed.
  • Eliminate two options first. "AWS is responsible for the cloud; you are responsible for what's in the cloud."
  • Flag hard questions and return; there is no penalty for guessing.
  • Avoid "exam dumps". They can be wrong or outdated, and using real leaked questions violates AWS's rules. When a quiz and the notes disagree, check AWS documentation.
